# Receta Git

Este repositorio ha sido creado como práctica para aprender a gestionar versiones de código y repositorios remotos.

## Ingredientes principales

Para que esta receta de código salga perfecta, necesitamos:
- Una terminal con Git instalado en el equipo.
- Una cuenta activa en GitHub.
- Ganas de practicar los comandos básicos (add, commit, push, pull).
